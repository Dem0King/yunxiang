项目概述

1.1 项目定位

云祥家具城线上展厅是一个面向 C 端个人客户的家具产品展示网站。核心功能是「看」——让客户通过手机或电脑快速浏览门店代理的品牌和产品，产生购买意向后引导到店或在线咨询。

设计方向：融合 Kimi 前端审美（Bento Grid + 毛玻璃 + 渐变）与喜临门官网的专业产品展示风格，做一个温暖、有品质感、不花哨的现代家具展示网站。

以下提供三个 LOGO 设计方向，选定后可交由设计师细化或用 AI 工具生成矢量文件。

方案 A — 云 · 椅（推荐）

云祥家具城
云朵造型同时勾勒出椅背轮廓，呼应「云祥」之名与家具行业属性
  • 形态：圆润云朵 + 椅背弧线双重意象
  • 颜色：暖木色 #c89b6f 主色，深胡桃 #3d2b1f 辅助
  • 气质：温暖、亲和、有家的感觉
  • 适用场景：门头招牌、网站 LOGO、微信头像、名片

方案 B — YX 字母组合

YX
YUNXIANG
Y 与 X 交织形成几何标记，现代感强，适合小尺寸场景
  • 形态：Y（生长）+ X（稳固）的几何交织
  • 颜色：深胡桃 #3d2b1f 单色，极简
  • 气质：现代、专业、国际化
  • 适用场景：网站 Favicon、APP 图标、水印

方案 C — 极简文字标

云祥
云祥 · YUNXIANG
「云祥」二字用衬线字体，右上方点缀暖木色圆点，简洁大方
  • 形态：纯文字 + 暖木色点缀圆点
  • 颜色：深胡桃文字 + 暖木色圆点
  • 气质：优雅、克制、高级感
  • 适用场景：全场景通用，尤其适合印刷品
建议
推荐方案 A（云 · 椅），辨识度最高且与家具行业关联性强。可搭配方案 C 的文字标作为组合 LOGO 使用。

设计系统

3.1 间距系统 (Spacing Scale)

4px 基准制，所有间距必须是 4 的倍数。这是保证页面视觉一致性的基础。

间距 Token (Tailwind 对应):
  4    → xs      组件内部最小间距 (图标与文字)
  8    → sm      组件内部间距
  12   → md      组件内部间距 (大)
  16   → base    组件之间默认间距
  20   → lg      列表项间距
  24   → xl      卡片间距 / 区块内部留白
  32   → 2xl     区块内部留白 (大)
  40   → 3xl     区块之间留白
  48   → 4xl     区块之间留白 (大)
  64   → 5xl     大区块之间留白
  80   → 6xl     移动端首屏区块间距
  96   → 7xl     桌面端首屏区块间距

使用规则:
  组件内部间距    → 8 / 12 / 16
  组件之间间距    → 16 / 24
  区块内部留白    → 32 / 48
  区块之间留白    → 64 / 80 (移动端 48 / 64)

动效方案

8.1 动效原则

三原则
1. 服务内容 — 动效引导注意力，不抢注意力
2. 有意义 — 不做无理由的装饰动画
3. 快速 — 交互动画 150-250ms, 入场动画 400-600ms
该用动效不该用动效
首屏标题入场 (第一印象)
卡片滚动入场 (节奏感)
导航栏渐变 (状态反馈)
数字滚动 (价格冲击力)
Hover 微交互 (反馈感)		 每个标题都逐字浮现
所有图片都 3D 倾斜
筛选时卡片翻转动画
页面切换时全屏遮罩
自动播放的背景动画

14
性能优化

14.1 图片策略

  • 所有产品图片转换为 WebP 格式 (比 JPEG 小 30-50%)
  • 使用 srcset 提供响应式图片 (1x/2x)
  • 非首屏图片懒加载 (loading="lazy")
  • 低质量占位图 (LQIP) 提升感知速度
  • 图片 CDN 缓存 (Vercel 自带)

14.2 动画性能

  • 只动画 transform 和 opacity (GPU 加速)
  • 避免动画 width/height/top/left (触发重排)
  • 大量元素动画时使用 will-change
  • 滚动动画使用 IntersectionObserver (Framer Motion 已内置)
  • 移动端减少动画数量 (性能优先)

14.3 首屏加载

  • 路由级别代码分割 (React.lazy + Suspense)
  • 产品数据预取 (首页加载时预取产品列表)
  • 关键 CSS 内联 (Tailwind 自动处理)
  • 字体预加载 (preload)
  • 目标: 首屏 LCP < 2.5s, FID < 100ms
